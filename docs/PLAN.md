# خطة البناء — برق

Claude Code بيبني المشروع **مرحلة مرحلة** بالترتيب هاد. بآخر كل مرحلة:
1. بيكتب شرح بالعربي في `docs/notes/phase-N.md`.
2. بيرفع على فرع المرحلة ويفتح Pull Request على `dev`.
3. **الفريق بيجتمع:** بيقرأوا الشرح، بيشغّلوا التطبيق، بيناقشوا الكود، وبيسألوا Claude عن أي إشي مش واضح. بعدها بيندمج وبنبدأ المرحلة الجاية.

التفاصيل الكاملة لكل خطوة (الشاشة، الصورة، الـ API، الملاحظات) بملفات `docs/tasks/` حسب الرقم المرجعي.

## توزيع الفريق (مش على الكود، على الفهم والمراجعة)
Claude بيكتب الكود، والفريق كله لازم يفهمه. اقتراح لكل مرحلة:
- **واحد** بيقرأ `docs/notes/phase-N.md` ويشرحه للباقي بالاجتماع.
- **واحد** بيجرّب التطبيق على جهازه ويسجّل أي فرق عن التصميم أو أي خطأ.
- **واحد** بيجرّب الـ API بـ Postman ويتأكد إن الشاشات بتعرض نفس البيانات.
- **واحد** بيراجع الـ Pull Request على GitHub ويكتب أسئلة على الكود.
وبتتبدّل الأدوار كل مرحلة، عشان كل واحد يمر على كل الأجزاء.
